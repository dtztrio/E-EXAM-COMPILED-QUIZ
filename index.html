Choose how you practice

Two modes, one quiz

Every quiz on the Dashboard can be run two ways. Switch between them depending on whether you're building speed or building understanding.

Timer Mode

Exam conditions

A countdown runs for the full session, just like the real thing. The clock doesn't pause, so you learn to pace yourself across all 100 questions instead of freezing on one.

  • Visible countdown, auto-submits at zero
  • Trains pacing and exam-day pressure
  • Best once you've already been through the material

No-Timer Mode

Learning pace

The same 100 questions, with the clock switched off. Take as long as you need on each one, think it through, and check your logic before you lock in an answer.

  • No countdown, no auto-submit
  • Built for a first pass through a new topic
  • Same solutions and scoring as Timer Mode
